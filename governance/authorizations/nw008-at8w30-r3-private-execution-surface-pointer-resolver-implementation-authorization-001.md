```text

  -> STRICT_DATA_PARSE
  -> PRIVATE_ROOT_DATA
  -> VALIDATION
  -> FIXED_PRIVATE_OWNER_MODULE_IMPORT
```

### 5.1 Authority model

```text
POINTER_RECORD_IS_AUTHORITY=NO
POINTER_RECORD_IS_DATA=YES

PRIVATE_ROOT_VALUE_IS_AUTHORITY=NO
```
