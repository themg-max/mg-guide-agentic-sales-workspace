dispatch-context binding that can be attested without contacting or reopening
the private source. It may not search, list, enumerate, discover, invoke, or
read from a private source or private data plane.

boundary, the corresponding receipt must not assert success and the predicate
must remain `UNKNOWN`.

## Future Predicate Reconciliation Rule

The future interface predicate may become `YES` only when
`NW008_AT8O33_INTERFACE_BINDING_ATTESTATION_RECEIPT_001` safely establishes all
interface properties, every forbidden-access result is `NO`, the pair-coherence
properties are `YES`, and `RECEIPT_RESULT=SATISFIED`.

The future operation predicate may become `YES` only when
`NW008_AT8O33_OPERATION_BINDING_ATTESTATION_RECEIPT_001` safely establishes all
operation properties, every forbidden-access result is `NO`, the pair-coherence
properties are `YES`, and `RECEIPT_RESULT=SATISFIED`.

```text
AT8O32_RESOLVES_INTERFACE_PREDICATE_TO_YES=NO
AT8O32_RESOLVES_OPERATION_PREDICATE_TO_YES=NO

MISSING_OR_INCOMPLETE_INTERFACE_RECEIPT_RESULT=
LOCATOR_INSPECTION_SOURCE_INTERFACE_IDENTIFIED_REMAINS_UNKNOWN

MISSING_OR_INCOMPLETE_OPERATION_RECEIPT_RESULT=
LOCATOR_INSPECTION_OPERATION_IDENTIFIED_REMAINS_UNKNOWN
MISSING_OR_UNREVIEWABLE_ATTESTER_AUTHORITY_PROVENANCE_RESULT=UNKNOWN
```

No receipt may infer an exact binding from `SUCCESS_SANITIZED`,
`NOT_AUTHORIZED_TO_DISCLOSE`, scope compatibility alone, or authorization
language alone.
