## Purpose and Resolution Boundary

This planning-only unit resolves whether a preexisting authoritative source is
available for each AT8O33 prerequisite. It uses only preexisting, safe,
authorized evidence and creates no binding, authority, safe shared reference,
Approved Doc, ingestion action, or AT8O33 receipt.

```text
SOURCE_AUTHORITY_RESULT_VOCABULARY=
FOUND_EXISTING|PROVEN_ABSENT|UNKNOWN
```

`FOUND_EXISTING` requires reviewable safe provenance. `PROVEN_ABSENT` requires
affirmative authoritative evidence of absence. A search failure or zero-result
search cannot establish either result, so an unresolved prerequisite remains
`UNKNOWN`.
