## 1. Governance decision

AT8O12 records the human governance decision on the merged AT8O11 metadata
inspection request. The request is granted, but only for a single sanitized
metadata-only inspection attempt.

This decision does not execute inspection, does not select a human principal,
and does not authorize any private record content retrieval.

## 2. Authorization scope

The authorization is limited to the merged AT8O11 allowlist and inherits the
same connector-safe alias restriction. A private source identifier may not be
disclosed unless it is returned as a connector-safe non-principal, non-secret
alias.
